GROWTH SPARK - Student Analytics Web App

HOW TO RUN
  Double-click index.html (opens in your browser). Keep the three files together:
  index.html, style.css, script.js.
  Chart.js, jsPDF and the fonts load from the internet, so you need to be online.

FIRST USE
  1. Choose Student or Teacher on the login screen, then Register.
  2. Students get IDs like STU1001. Teachers get IDs like TCH1001.
  3. Teacher registration needs the access code. The default is TEACH2026.
     Change TEACHER_CODE in script.js before you share the app.

PAGES
  Dashboard, Early warnings, Students, Segments, Focus quiz, Guidance,
  Teachers' room (teachers only), Notifications, Account, Manage data.

GOOD TO KNOW
  - Accounts and messages are saved only in the browser you use. This is a demo,
    not real security. Real login and cross-device messages need a backend
    (for example Firebase).
  - firebase-auth.js (sent earlier) is the Firebase version of login and register.
